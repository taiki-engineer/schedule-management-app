## ✨ 主な機能

- ユーザー登録・ログイン（JWT認証）
- ホーム画面で今日の予定・タスク・完了／未完了／総タスクの数値を表示
- スケジュール追加
- スケジュール編集
- スケジュール削除
- 予定一覧表示
- タスク追加
- タスク完了チェック
- タスク削除
- カレンダー表示
- カテゴリーごとの色分け
- レスポンシブ対応（PC・スマホ）

ユーザーごとに予定・タスクを管理できるようになっています。
